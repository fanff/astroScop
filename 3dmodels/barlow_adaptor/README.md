# Barlow adaptor

OpenSCAD ring that spaces a Barlow to a fixed length for a 2" focuser.

## Dimensions

- **Outer diameter** — fits a standard 2" telescope mount / focuser barrel
- **Inner diameter** — bore for the Barlow body
- **Height** — adaptor length along the optical axis

Clearance parameters (`outer_clearance`, `inner_clearance`) can be tuned for print fit.

## Usage

Open `barlow_adaptor.scad` in [OpenSCAD](https://openscad.org/), adjust parameters if needed, then **Export → STL**.
